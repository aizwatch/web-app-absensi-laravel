Kirim perintah set timezone ke semua mesin via Fingerspot Cloud API. Mesin akan menyesuaikan jam ke timezone yang dipilih.

Mesin absensi selain REVO/VIDA/VEGA/VIVO series akan restart otomatis saat perintah dieksekusi.
